# שמות עבריים לגרסאות (מהדורות ספרים, book_version) — השם שהאפליקציה מציגה
# (heVersionTitle) במקום versionTitle האנגלי של ספריא.
#
# כללי רישום:
#   שורות ריקות ושורות שמתחילות ב-# — מתעלמים מהן.
#
#   versionTitle => שם עברי                 שורה כללית: בכל הספרים שבהם הגרסה מופיעה.
#   שם ספר | versionTitle => שם עברי        שורת ספר: בספר הזה בלבד.
#
#   שורת ספר קובעת תמיד, גם כשלגרסה יש שם עברי בספריא (versionTitleInHebrew).
#   שורה כללית ממלאת רק גרסה שאין לה שם עברי בספריא, ולעולם לא דורסת אותו.
#   שורת ספר גוברת על שורה כללית.
#
#   שם הספר: הכותרת העברית או האנגלית, כפי שמופיעה בסכמות ספריא (heTitle/title).
#   שם הגרסה: versionTitle האנגלי בלבד, כפי שמופיע בקובץ הגרסה.
#   ההשוואה מדויקת: רק רווחים בקצוות נחתכים. בניגוד לבלאקליסטים — אין התעלמות
#   מרישיות, מרווחים כפולים או מגרשיים/מרכאות.
#   המפרידים הם " => " (עם רווחים) ו-| (צינור); לכן שם שמכיל אותם אינו נתמך.
#   השם חל אחרי black_versions.txt, שממשיך להתאים לשם העברי המקורי של ספריא.
#
#   שורה שלא התאימה לאף גרסה (למשל: ספריא שינתה את שם הגרסה) — אזהרה בלוג בלבד.
#   שורה פגומה או מפתח כפול — הבנייה נופלת.
#   שתי שורות לאותה גרסה באותו ספר, אחת בכותרת העברית ואחת באנגלית — אזהרה בלוג,
#   והשורה המוקדמת בקובץ (מספר שורה נמוך) קובעת.
#
# דוגמאות (מנוטרלות):
#   Torat-Emet => תורת אמת
#   בראשית | Mechon-Mamre => מכון ממרא
